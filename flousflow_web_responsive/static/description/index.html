FlousFlow Responsive

A responsive, modern Odoo 19 backend experience

FlousFlow Responsive improves the Odoo 19 Community web client on desktop and mobile screens while keeping the standard Odoo workflow and navigation familiar.

Key features

  • Responsive backend layout for smaller screens.
  • Improved navbar, burger menu, and home menu behavior.
  • Share URL support in the web client.
  • Light and dark mode styling.
  • UI refinements for list, kanban, pivot, and search views.
  • Designed for Odoo 19 Community installations.

Installation

Install the module from the Odoo Apps menu after adding the repository to the Odoo 19 addons path. If the former ica_web_responsive module is installed, uninstall it before enabling flousflow_web_responsive.
